About

I am a Data Engineer at NCR Voyix, where I design ETL and ELT pipelines for enterprise financial and customer data. My work covers ingestion into Azure Data Lake, layered models in Synapse and Databricks, reconciliation across systems, and the monitoring that keeps mission-critical reports on time. Month-end financial reporting automation

MRF job from 12+ hours to 1 to 1.5 hours

Moved the General Ledger and Management Reporting Foundation procedures from Synapse to Databricks. The General Ledger data is transactional and refreshes every 15 minutes, so I built an Auto Loader based framework for it.

Databricks, PySpark, Auto Loader

Oracle EPM, GL and MRF reconciliation

Audit-ready financial reporting

Pulls Oracle EPM data and reconciles it with General Ledger and MRF data across nine segments, including account, department, company and geography codes. A Power BI dashboard shows where source, GL and MRF agree.

Databricks, Oracle EPM, Power BI

Site count automation

Early weekly view of active customer sites

Supports the company's reported revenue-per-site metric. Data from Salesforce, billing, quoting, ERP and other sources lands in a silver layer. SQL procedures apply the site-count logic and build a gold layer, exposed as weekly and monthly views by product and site type.

Azure Data Factory, Synapse, Synapse serverless

Data validation and monitoring framework

Problems caught at landing, not in reports

Bronze-layer checks confirm each file is not empty, record counts match the source, key and amount columns have no nulls, and data is fresh. I also built a detector for zero-byte files with proactive alerts.

ADF, Logic Apps, Synapse

Secure regional report delivery

CSV attachments replaced with a controlled hand-off

Eight regions used to receive data as emailed CSV files. An ADF pipeline now builds one table per domain with domain-specific procedures. A Logic App writes the files to a storage container and emails the location, with each month kept in its own partition for history.

ADF, Synapse, Logic Apps, Azure Storage
